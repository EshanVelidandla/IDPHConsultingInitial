## Deviations from the plan
- Added: a table with every cell empty is refused. The plan allows empty cells, but an all-blank file would otherwise erase a published table. Easy to remove if unwanted.
- Parsing uses the `csv` module, not pandas, which would accept `NA` and `null` as empty, accept `inf`, and rename duplicate year columns.
- Choices the plan left open: column order is enforced, row order is not. County names must match exactly, with no case or space tolerance. `" "` counts as non-numeric, not empty. A BOM is accepted and stripped before writing, because `/export/csv` serves the file as is. CRLF is kept.
- The `rows` value in the upload response is now `len(VALID_COUNTIES)`, which equals the row count of any accepted file.
- Batch 0a (`IDPH_VAR_DIR`, `IDPH_TABLES_DIR`) was not added. Tests monkeypatch `death_rates_dir`, `DATASET_BACKUP_DIR`, `AUDIT_FILE` and `_TABLE_CACHE` instead.
