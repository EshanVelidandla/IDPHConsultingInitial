## Deviations from the plan

1. **`API_BASE` edited.** The plan says `constants.ts` has no imports and can be tested under Node, but `import.meta.env.VITE_API_BASE` throws there because `env` is undefined. Changed to `import.meta.env?.VITE_API_BASE`. Any other issue importing `constants.ts` in Node hits the same problem.
2. **Test file name.** The plan puts the `CANONICAL_COUNTY` checks in `tests/analytics.test.mjs`. They are in `tests/county-names.test.mjs` to avoid an add/add conflict with batch 3.
3. **Null prototype.** `CANONICAL_COUNTY` has no prototype, so `/county/constructor` gives the not-found message instead of passing a function along as a name. It is still a plain `Record` to callers.
4. **Second decode removed (not in the plan).** The router already decodes the param, and `decodeURIComponent` a second time throws on a literal `%`, as in `/county/100%25`. Needed for unknown names to reach the not-found message.
5. **Redirect keeps `location.state`.** It also uses an absolute path. The plan's `navigate(canonical, ...)` would resolve relative to the route, and dropping state would lose the incoming cause and the Scorecard hue.
6. **Layer `key` left unchanged.** The stable key belongs to #22. The constant lookup fixes #33 with or without it.
