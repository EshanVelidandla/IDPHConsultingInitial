## Deviations from the plan

- The plan's acceptance uses `SMOKE_FAIL` from #30, which is not in this worktree and was not added. The new test file covers the same failures, including the mutations, which could not safely hit the real backend because #13 is unfixed here.
- The spec lists five tabs. The Audit tab load is also wrapped, per the decision table's "all tabs".
- Load errors appear in a banner in the table panel, not the form's feedback slot, because forms are hidden from some roles. Mutation errors use the form slot. Presets had no slot, so one was added.
- Beyond the plan: on a failed load, the panel heading reads "Could not load" and the empty row reads "Not loaded", so an outage does not look like an empty table.
- A failed user role save keeps the editor open.
