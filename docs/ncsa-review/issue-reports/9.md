## Deviations from the plan
- **The plan file changed during this work.** `02-plan.md` was rewritten at 13:49 on 2026-11-02 after I had read it. The earlier text asked for a `slow`-marked test and sub-items 9a to 9c; the current text asks for a test gated by `PIPELINE_REGEN=1`. The test does both. The owner of the pipeline should confirm which plan version is meant.
- Override is one environment variable, `PIPELINE_OUTPUT_ROOT` in the new `pipeline_paths.py`, rather than function parameters. Reason: writer lines stay untouched, so #26 and #31 merge more simply, and the test can drive the real `run_pipeline.py`, including `validate_death_rates`. `build_population`'s two outputs and `validate_death_rates`' paths use it too.
- Provider comparison skips on its own when `.asc` files are pointers; population and deaths still run in that case, since they do not need LFS.
- `REPO` is normalized in `test_pipeline.py` and `deaths_pipeline.py`. Not in the plan. Unnormalized `..` paths passed the Windows 260 character limit in this long worktree path and caused 5 `FileNotFoundError` failures in existing tests. Those failures come from the path length, not the code.
- `build_population` prints `normpath` instead of `relpath`, which raises on Windows when the output is on another drive.
