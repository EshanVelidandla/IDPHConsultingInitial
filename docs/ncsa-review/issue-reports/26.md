## Deviations and additions to the plan

1. **Adams trips the drift check before audit.** Removing Adams 2019 gives -0.75%, which is over 0.5%, so through `main` the error comes from `_cross_check_state`, not `audit`. The plan keeps that check in `compute_rates`, so I kept it and made its error name any absent county. Hardin (about 0.05%) passes drift and is caught by `audit`. Both paths are tested, plus `audit` called directly with Adams removed.
2. **Added: blank all-cause cell fails `audit`.** A county row can be present with a blank `Total_Deaths`, which the county set cannot see and which would produce the issue's NaN. Today's data has none.
3. **Added: missing ILLINOIS total fails the cross-check.** It used to `continue` silently, which also switched off the backstop for that year. `audit` excludes ILLINOIS from its expected set, so nothing else caught it.
4. **Added: zero or NaN population raises**, in addition to the absent-row case the plan names. The old `continue` on this path blanked a county with no message at all.
5. `README.md` changed, to keep its statement about the cross-check true.
6. Tests are in a new file rather than `test_pipeline.py`, to reduce merge conflicts with #9, which also adds a synthetic `compute_rates` test.
