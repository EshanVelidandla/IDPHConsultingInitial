## Deviations from the plan

1. **Line numbers were stale, as expected.** `toRate` already exists at `3775601`, so it was reused, not added. Code was found by identifier.
2. **Bivariate overlay split with #7e.** `bivariateColor` now treats only a null rate as missing, so a zero-mortality county is colored. The provider half is left for #7e: provider 0 still falls through to mortality tints in `getStyle`, and the `!provVal` guard remains. Merge note: #7e edits the same lines.
3. **Insights HPSA correlation is left for #7c.** `corrScatter` now keeps zeros, which is required here, so with HPSA selected r runs over 102 counties on category codes (the proposal's +0.043). That is still meaningless until #7c removes HPSA from the select.
4. **COVID base stays 2019, as a named constant.** `COVID_BASE_YEAR` is a meaningful reference, not a data bound. The end year is `lastYear`. A zero base year now keeps its change and shows no percentage.
5. **Small additions, same root cause, not named in the plan:**
   - Insights distribution count showed `n/a` for an empty bucket; it now shows 0.
   - CountyDrillDown slope of exactly 0 showed `n/a`; it now shows the value.
   - Providers `metricColor` painted a zero with the no-data gray; it now uses the low color.
   - Pulse `yearRate` and `deltaYoY` no longer test truthiness.
6. **The `test` script runs only `tests/logic.test.mjs`,** per Batch 1. Other issues adding that file will produce an add/add conflict; keep all test bodies.

## Left alone (other issues)
