## Findings beyond the issue text

- On Priority the spinner sits inside the `selectedCause &&` block, so the stuck state never shows an overlay there. The symptom is a blank view, because the empty state also waits on `!loading`. The regression test checks for the empty state on Insights and Priority for this reason.
- Clearing the cause on Map and Insights still leaves the previous rows in `countyData` and `deathData`. Priority clears them. This is existing behavior and not part of #25, so I left it.
