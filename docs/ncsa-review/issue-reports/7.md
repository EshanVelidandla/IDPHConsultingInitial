## Deviations from the plan

1. **Layouts left out of the patch**, as above.
2. **#31b not applied here.** The plan's Batch D pairs it with #7, but it belongs to #31. State rows therefore still use Census weights and differ slightly from the plan's AHRF-weighted figures, for example beds 2008 is 307.19 against 307.23. The plan allows for this movement.
3. **`bivariateCell` added to `analytics.ts`.** The plan names `bivariateColor`, which stays in `MapView` as a thin color lookup. The logic moved so it can be tested without Leaflet.
4. **`rateMap` and `providerMap` became nullable through `toRate`**, the shape #5a specifies, because 7e needs true nulls. Side effect: a null cell's mortality border is now no-data, which is half of #29. Expect a small overlap with #5a and #29 on these lines. `tileColor`'s zero handling is left to them.
5. **Map tooltip also changed:** it now shows zero providers, and HPSA as a category name instead of a code.
6. **`imputedNote` wording:** interpolated years read "2018 interpolated between 2017 and 2019". Filled years at the ends read "2022 carried from 2020", as the plan's example does.
7. **Comment basis for years staying imputed:** the addendum left 2018 as "not verified". I searched every layout on disk: none defines beds 2018 or psychiatry 2009 or 2018. That does not prove a release outside the repo lacks them.
