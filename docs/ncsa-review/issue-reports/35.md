## Deviations from the plan
- `exportTarget` is separate state in `AppShell`, passed as a prop, rather than a field of `SharedState`. Views call `setShared({...shared})`, and an effect-driven field there would risk stale overwrites.
- Map, Insights and Priority do not register. A route list in `resolveExport` derives their target from `shared.selectedCause`, which avoids editing three contended files.
- Regression check is a new file rather than a `smoke.mjs` action, to keep merging simple and need no backend.
- Providers CSV has no column marking interpolated years, and HPSA exports raw codes (0, 1, 2) with no category text. The plan did not ask for either; worth considering later.

## Behaviour to note
County profile previously exported the shared cause if one was set. It now disables Export, since it has its own cause selection and the plan registers only Access, Pulse and Providers.
